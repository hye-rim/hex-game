# 헥스 ⬢

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 헥스(2인). [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- **판**: 육각형 칸이 마름모로 놓인 판. 7·9·11줄 중 고른다(빠른 대전은 9줄). 칸마다 이웃이 6개(같은 줄 양옆, 위줄 둘, 아랫줄 둘)
- **목표**: 첫 번째 사람(**분홍**, 먼저)은 위·아래 변을, 두 번째 사람(**노랑**)은 왼쪽·오른쪽 변을 자기 돌로 이으면 이긴다. 번갈아 빈 칸에 돌을 하나씩 놓고, 놓은 돌은 움직이거나 잡히지 않는다
- **무승부 없음**: 판이 다 차면 반드시 한쪽만 이어져 있다 (`test/logic.test.js` 가 무작위로 채운 판으로 확인)
- **스왑 규칙(켜고 끌 수 있음)**: 첫 번째 사람이 첫 돌을 놓은 직후, 두 번째 사람은 두는 대신 **그 돌을 가져갈 수 있다**. 두 변이 서로 다르므로 돌을 대각선으로 뒤집어(줄↔칸 맞바꿈) 두 번째 사람의 돌로 바꾸고, 다시 첫 번째 사람이 둔다. 첫 돌이 가운데 가까우면 가져가는 게 이득이라 먼저 두는 쪽이 너무 유리하지 않게 된다
- **컴퓨터**: 상대를 막으며 두 변을 잇는 데 **더 놓아야 하는 돌 수**(상대 돌은 못 지나가는 최단 거리)의 차이로 평가한다. 쉬움은 한 수 만에 이길 수 있으면 대체로 이기고 아니면 기존 돌 근처 무작위, 어려움은 한 수 만에 이기거나 막고 아니면 후보를 상대 응수까지 보는 2수 앞 탐색을 하며 **네 번에 한 번쯤(`HARD_SLIP`)은 쉬움처럼 둔다**. 컴퓨터는 첫 돌이 가운데쪽이면 스왑한다. 컴퓨터 대전은 "다시 하기"마다 먼저·나중이 바뀐다
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`, 방을 만든 사람이 판 크기·스왑을 정한다) · 재접속(30초) · 한 번 놓을 때마다 60초(넘기면 시간패, 기권·이탈도 패배) · 한 판 더(먼저·나중 교대). 모든 동작은 `act` 하나(`{type:'place', cell}` 또는 `{type:'swap'}`)로 오고 서버가 같은 규칙(`public/logic.js`)으로 검사한다. 숨은 정보가 없어 판 전체를 보낸다
- 화면: 이름표에 "n개 필요"(내가·상대가 두 변을 잇는 데 앞으로 최소 몇 개 더 필요한지), 방금 놓은 돌에 점, 이긴 길에 흰 테두리. **손가락은 칸을 한 번 눌러 미리 본 뒤 같은 칸을 한 번 더 눌러야 놓이고**(칸이 작아서 잘못 누르기 쉬움), 마우스는 한 번에 놓는다
- 컴퓨터를 이긴 횟수는 `hexWins` (로비 표시용), 온라인 전적은 `hexOnline`

규칙·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(이웃 수, 반대 대각선만 이어짐, 스왑 조건, 무승부 없음, 무작위 판 종료, 최단 거리, 이기기·막기, 스왑 판단, 어려움이 쉬움을 이김), `test/server.test.js`(서버를 띄워 매칭 · 입력 검사 · 돌과 스왑이 두 화면에 똑같이 반영 · 무작위로 끝까지 · 방 설정 유지 · 기권 · 한 판 더 · 시간 초과 · 재접속).
